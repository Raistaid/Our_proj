## Что ещё не проверено

Браузерная раскладка HTML/CSS, живое управление в браузере, официальные Android/iOS-песочницы, реальный шаринг, поведение звука на устройстве, время холодной загрузки, FPS, длительность сессии и понятность для 11–13 лет. Эти пункты должна выполнить команда.

Публичный репозиторий, URL игры и презентация не созданы автоматически.

## Список для реального устройства

Заполняет участник 3, участник 1 исправляет логику, участник 2 — визуальные проблемы.

- [ ] Открывается именно неизменённая официальная песочница.
- [ ] Вставленный URL открывает нужную версию игры.
- [ ] В свежем запуске нет звука и старого прогресса.
- [ ] Измерено время до доступного действия; ориентир задания — до 3 секунд.
- [ ] На 320/360/390 px читаются все записки.
- [ ] Видны и нажимаются палитра, отмена, подсказка и проверка.
- [ ] Работают тап и перетаскивание.
- [ ] Отпускание пальца вне кадра не добавляет наклейку.
- [ ] Поворот во время жеста не добавляет случайную наклейку.
- [ ] Второй палец не мешает первому.
- [ ] Заклеенный главный предмет блокирует успех.
- [ ] Заклеенная обычная записка блокирует успех и объясняется.
- [ ] «Отменить» возвращает кадр к исправимому состоянию.
- [ ] Успешный кадр блокирован; переход ведёт к следующему.
- [ ] На последнем кадре подсказка сначала недоступна, после первой ошибки доступна.
- [ ] Получается итоговый PNG без открытых секретных записок.
- [ ] SHARING_EVENT вызывает системный выбор приложения; отправлять изображение кому-либо для этой проверки не обязательно.
- [ ] Системное окно можно отменить и вернуться в игру.
- [ ] В логе один COMPLETED_EVENT после полного прохождения.
- [ ] После повторного прохождения в том же открытии второго COMPLETED_EVENT нет.
- [ ] Закрытие через × действительно закрывает экран игры.
- [ ] Новое открытие начинает игру с нуля.
- [ ] Переключатель включает/выключает короткие звуки.
- [ ] В Network отсутствуют 404 и неожиданные внешние обращения.
- [ ] Игра открывается из подпапки публичного домена.
- [ ] После изменения пути JSON/повреждения данных появляется пробный кадр без COMPLETED_EVENT.
- [ ] Сессия измерена на новых игроках, ориентир 3–5 минут.
- [ ] Плавность оценена на устройстве; целевой ориентир задания — 60 FPS.

Результат каждой проблемы: устройство, шаги, ожидаемое, фактическое, снимок/лог при необходимости. Не ограничивайтесь записью «не работает».

## Приёмка перед сдачей

Четыре пункта из задания: презентация, рабочий показываемый прототип, публичный репозиторий в общей таблице, работа трека B в неизменённой Android- или iOS-песочнице. Сам архив не заменяет эти действия.

Перед защитой пройдите последний коммит по публичной ссылке на том устройстве, которое будете показывать.
