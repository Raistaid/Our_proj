# Context

Sandbox-приложение для хакатона «Сбер — Создаем эмоции»: открывает HTML5-игру команды так же, как её откроет приложение СберKids, и показывает, как приложение реагирует на события со страницы.

## Glossary

**Page** — веб-страница игры команды, открытая в приложении. Может быть внешней (по URL) или встроенной Test Page.

**Test Page** — страница, поставляемая внутри приложения, с кнопкой на каждый Page Event. Демонстрирует и документирует контракт.

**Bridge** — односторонний канал «страница → приложение». Page сообщает о событиях, приложение решает, что с ними делать. Данные из приложения в Page не передаются.

**Page Event** — одно сообщение, отправленное Page через Bridge, с типом из контракта хакатона: `CLOSE_EVENT`, `FINISH_EVENT`, `COMPLETED_EVENT`, `VIBRATION_EVENT`, `SHARING_EVENT`. Сообщение с другим типом — Unknown Event; сообщение, которое не удалось разобрать, — Invalid Message.

**Bridge Action** — реакция приложения на Page Event (закрыть Game Screen, вибрация, показать системное «поделиться» и т. д.). Один Page Event даёт ноль или больше Bridge Actions.

**Game Screen** — экран, на котором отображается Page.

**Event Log** — хронологический список того, что произошло на Game Screen за одну сессию: загрузка Page и её ошибки, полученные Page Events, Unknown Events, Invalid Messages, выполненные Bridge Actions и Blocked Navigations. Живёт только пока открыт Game Screen.

**Blocked Navigation** — попытка Page уйти за пределы своего Origin (переход по ссылке наружу, новое окно). Sandbox её не выполняет и фиксирует в Event Log как нарушение требований хакатона.

**Launcher** — стартовый экран: ввод URL Page, история адресов, запуск Test Page.

**Origin** — источник (scheme + host), с которого пришёл Page Event. В sandbox принимаются события с любого Origin; Origin фиксируется.
