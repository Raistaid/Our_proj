# Засвет — Android-песочница

Android-проект на основе [песочницы хакатона Сбера](https://github.com/vveidi/sber-hse-hackathon-2026-android). Кнопка **«Играть в „Засвет“»** открывает встроенную игру без сервера и интернета. Ввод URL, тестовая страница контракта и журнал событий сохранены.

## Запуск

1. Установите Android Studio с поддержкой Android Gradle Plugin 9.2.1, JDK 21 и Android SDK 36.1. Минимальная версия устройства — Android 8.0 (API 26).
2. Откройте папку `android-sandbox` как проект. Папка `game` должна находиться рядом с ней. В [Android ZIP](https://github.com/Raistaid/Zasvet/raw/refs/heads/main/downloads/zasvet-android.zip) обе папки уже лежат внутри `zasvet-android`.
3. Дождитесь синхронизации Gradle и запустите конфигурацию `app` на устройстве или эмуляторе.
4. Нажмите **«Играть в „Засвет“»**. Кнопка журнала вверху показывает сообщения игры и действия оболочки.

Исходники игры берутся из `../game`: задача `syncGameAssets` копирует их в сгенерированные assets перед сборкой. Отдельную копию игры вручную обновлять не нужно. Страница открывается по адресу `https://appassets.androidplatform.net/assets/game/index.html` через `WebViewAssetLoader`; ES modules, JSON и изображения сохраняют относительные пути.

ZIP содержит исходники песочницы. Готовый APK отдельной Java-оболочки находится в `downloads/zasvet-android.apk` в репозитории; эта песочница не используется для его сборки.

## Контракт и поведение

| Сообщение игры | Действие оболочки |
|---|---|
| `CLOSE_EVENT` | Закрывает игру и возвращает стартовый экран |
| `COMPLETED_EVENT` | Показывает «Прогресс засчитан»; отмечает повторы в журнале |
| `FINISH_EVENT` | Показывает «Игра завершена» |
| `VIBRATION_EVENT` | Вызывает тактильный отклик |
| `SHARING_EVENT` | Открывает системное меню с текстом и PNG-постером |

Сохранены настройки официальной песочницы: очистка cookies, кэша и Web Storage при открытии и закрытии, запрет переходов на другой origin и новых окон, запуск звука по действию пользователя и сохранение игры при повороте экрана. HTTP оставлен для локальной разработки. Это диагностическая оболочка: адрес можно менять на стартовом экране.

Чтобы проверить игру с компьютера, запустите `npm start` в корне репозитория и введите `http://10.0.2.2:8000/` на эмуляторе. Для телефона запустите сервер с `HOST=0.0.0.0 npm start` и укажите локальный IP компьютера. События можно отдельно проверить кнопкой «Открыть тестовую страницу».

## Проверки без APK

Из папки `android-sandbox`, с JDK 21 и установленным Android SDK:

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Команда компилирует код, проверяет обработчики сообщений и адресов, запускает Android Lint. Задачи упаковки APK в неё не входят. Проверка на устройстве выполняется отдельно через Android Studio.

Архивы для README обновляются из корня Git-репозитория (скрипт упаковки не входит в Android ZIP):

```bash
python3 tools/package-downloads.py
python3 tools/package-downloads.py --check
```
