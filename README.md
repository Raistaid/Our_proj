# Засвет: наклей всё!

Рабочая основа HTML5-игры для трека B СберKids. Аудитория — 11–13 лет. Ребёнок читает записки на вымышленной картинке, закрывает личные сведения смешными наклейками и сохраняет рисунок и обычные идеи видимыми.

**Цель обучения:** после игры ребёнок различает сведения для доступа и личные сведения, которые стоит убрать из публичной картинки, и обычный контент, который можно оставить.

## Сначала запустите

На компьютере с Node.js откройте терминал в папке проекта, где лежит этот README:

    npm.cmd start

Откройте http://localhost:8000. Сервер раздаёт текущую папку game без кеширования; в терминале его нужно оставлять работающим. Остановить — Ctrl+C. Если порт занят, используйте `npm.cmd start -- 8001` и http://localhost:8001. В macOS/Linux команда называется `npm start`.

Этот способ открывает сервер только на текущем компьютере. Для проверки с телефона можно вместо него запустить Python 3:

    python3 -m http.server 8000 --directory game --bind 0.0.0.0

В Windows команда Python может называться иначе:

    py -m http.server 8000 --directory game --bind 0.0.0.0

Откройте http://localhost:8000 на компьютере. Телефон в той же Wi-Fi-сети открывает http://IP-КОМПЬЮТЕРА:8000. Подставьте IPv4 компьютера; localhost на телефоне ведёт на сам телефон. Не запускайте игру двойным кликом по index.html: загрузке модулей и JSON нужен HTTP.

Сервер оставляйте работающим во время игры. Остановить — Ctrl+C. Команда с bind 0.0.0.0 открывает сервер в вашей локальной сети; она нужна для телефона.

**Ничего устанавливать через npm для самой игры не нужно.** В поставке нет сторонних зависимостей, сборки или бэкенда.

## Что уже реализовано

- Пять кадров, три собственные SVG-наклейки и три фона.
- Перетаскивание или выбор наклейки + тап по кадру.
- Фиксированный размер всех наклеек: 0.44 ширины × 0.18 высоты кадра. Превью и установленная наклейка совпадают; у края меняется только положение.
- В панели выбора наклейки показаны в том же размере, что и на кадре.
- Уже поставленную наклейку можно перетащить; перенос не расходует новую наклейку и отменяется кнопкой «Отменить».
- Чтобы убрать наклейку, перетащите её за край кадра и отпустите. «Отменить» возвращает её на прежнее место.
- Проверка полного закрытия секрета; защита главного предмета, подписи и обычной записки.
- Отмена хода, подсказка, объяснение ошибки, повторное прохождение.
- Последний кадр с подсказкой только после первой проверки.
- PNG последнего подготовленного кадра 720 × 960.
- Пять событий приложения через window.postMessage. COMPLETED_EVENT один раз за открытие страницы, включая повторную игру.
- Звук выключен при старте; синтезируется собственный короткий сигнал после включения.
- Запасной пробный кадр при недоступном или повреждённом JSON.

## Проверки после правок

Из корня проекта, где package.json, при установленном Node.js:

    node --test tests/*.test.mjs
    node tools/check-content.mjs

В Windows можно запустить весь набор через npm, включая новые проверки:

    npm.cmd test

Проверка контента ищет решение каждого кадра с каждой из трёх наклеек, проверяет защиту обычных записок, отмену ошибки, последний самостоятельный кадр, пути и размер game. package.json содержит только команды разработки, зависимости отсутствуют.

## Где что менять

| Путь | Что находится |
|---|---|
| game/index.html | Экраны и кнопки |
| game/styles/game.css | Внешний вид и мобильная раскладка |
| game/data/content.json | Все сцены, тексты, координаты, лимиты |
| game/assets/scenes | Фоны SVG |
| game/assets/stickers | Три авторские наклейки SVG |
| game/src/app.js | Переходы между экранами, связь всех частей |
| game/src/game.js | Ходы, отмена и проверка результата |
| game/src/geometry.js | Прямоугольники и пересечения |
| game/src/input.js | Мышь, палец, перетаскивание |
| game/src/renderer.js | Рисование Canvas |
| game/src/assets.js | Загрузка графики и обновление после медленного ответа |
| game/src/export.js | Безопасный экспорт PNG |
| game/src/bridge.js | Сообщения приложению |
| game/src/content.js | Загрузка и валидация данных |
| tests | Автоматические проверки без библиотек |
| tools/make-assets.py | Исходный генератор графики и JSON |

**Важно:** make-assets.py заново создаёт графику и content.json. После ручных правок не запускайте его случайно: он перезапишет изменения.

На сервер передаётся только содержимое game: index.html, styles, src, data, assets. Остальные папки предназначены для разработки. Можно разместить весь репозиторий на статическом хостинге и открыть URL с окончанием /game/.
