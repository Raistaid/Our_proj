# Засвет: наклей всё!

HTML5-игра для трека B «Игры» хакатона СберKids «Создаём эмоции». Аудитория — 11–13 лет, контент 0+/6+.

Ребёнок готовит пост для открытой ленты. На вымышленных кадрах вместе с главным предметом случайно оказались личные сведения: адрес, код получения, пароль, место встречи. Нужно найти их, закрыть смешными наклейками и при этом оставить на виду то, ради чего пост и делался.

> **Цель обучения:** после игры ребёнок замечает и скрывает личные сведения на изображении перед его открытой публикацией и отличает их от обычного контента, который можно оставить.

## Как играть

1. **Читай записки.** Код, пароль, адрес и место встречи — это личное.
2. **Тяни наклейку** (носок, облако или огурец) на середину записки с личными данными. Можно и так: выбрать наклейку и коснуться кадра.
3. **Жми «Готово».** Узкий край записки можно оставить видимым. Остальные объекты можно заклеивать.

Шесть кадров. Ошибка объясняется одной конкретной причиной, и кадр можно исправить сразу, без потери попытки.

## Что внутри

**Игровой процесс**
- 6 кадров на пяти сценах: рюкзак, доска заметок, телефон, компьютер с перепиской и посылка. Телефон встречается один раз; финальная доска — самостоятельная проверка.
- Записки встроены в сцену: уведомление на телефоне, бирка на верёвочке, бейджик на рюкзаке, бумажная записка. Секретные и обычные записки бывают в любой из этих форм, поэтому секрет нельзя угадать по виду, только прочитав.
- Наклейки закрывают внутреннюю область записки непрозрачными подложками разных форм. Область проверки отступает на 8 логических пикселей с каждой стороны; у маленьких записок отступ ограничен четвертью соответствующего размера. Несколько наклеек могут закрывать область вместе, но щели и прозрачные углы не засчитываются. Подсказка показывает эту же область.
- В сценах используются читаемые учебные данные: номер телефона, шестизначные коды, вымышленный адрес и тестовая карта.
- Наклейки можно переносить, убирать за край кадра и отменять.
- Подсказка по запросу. В последнем, самостоятельном кадре она доступна только после первой проверки.

**Реакции и виральность**
- **Лента реакций.** Готовый кадр становится постом: лайки считаются, подписчики шутят про наклейки, которые стоят на кадре («Носок в очках — легенда 😂»).
- **Подозрительный подписчик.** Если секрет остался виден, под объяснением появляется его реплика («Спасибо за код, посылку заберу сам 😏»). Последствие ошибки видно по реакции зрителя, без запугивания.
- **Звание агента** на финале по итогам игры («Агент Носок», «Мастер маскировки»…) и сумма лайков.
- **Постер для «Поделиться»:** PNG 720×960 с кадром, званием, лайками и комментарием. Все секреты на нём закрыты.

**Живые сцены**
- Часы идут, солнце мерцает, робот моргает, лампа светится, над кружкой и чайником поднимается пар, мигает гирлянда.
- Сцена отвечает на каждую новую наклейку (робот удивлённо моргает, чайник пыхтит), после готового кадра сыплется конфетти.
- На стартовом экране — анимированное демо «как играть», на первом кадре — палец-подсказка.

**Звук и музыка**
- Собственные звуки и тихая весёлая мелодия, синтезированные в коде: без файлов и чужой музыки.
- По умолчанию выключены и включаются в настройках ⚙: там же громкость музыки и эффектов и звуки кнопок. Код рассчитан на то, чтобы звук на iPhone был слышен и в беззвучном режиме.

**Повторная игра**
- «Ещё один заход» показывает записки в другой раскладке: ответы нельзя запомнить, кадр нужно прочитать заново.

## Почему это учит, а не просто развлекает

- **Применение, а не викторина.** Ребёнок сам решает, что на картинке личное, и сам это прячет. Пройти, не прочитав записки, нельзя.
- **Свобода оформления.** Обычные записки и главный предмет можно украшать; готовность зависит от закрытия личных данных.
- **Ошибка объясняется, а не наказывается.** Одна конкретная причина и реакция «зрителя» вместо слова «неправильно».
- **Перенос навыка.** Последний кадр самостоятельный, а на повторе записки стоят в новых местах.

### Детали механики
- Шесть кадров, три собственные SVG-наклейки и пять фонов.
- Перетаскивание или выбор наклейки + тап по кадру.
- Три формы: прямоугольный носок 144 × 76.8 px, круглое облако диаметром 108 px и огурец на квадрате 108 × 108 px со скруглёнными углами. Превью и установленная наклейка совпадают; у края меняется только положение.
- В панели выбора — компактные иконки персонажей; на кадре наклейка имеет фиксированный размер.
- Уже поставленную наклейку можно перетащить; перенос не расходует новую наклейку и отменяется кнопкой «Отменить».
- Чтобы убрать наклейку, перетащите её за край кадра и отпустите. «Отменить» возвращает её на прежнее место.
- Проверка полного закрытия внутренней области каждой личной записки; обычные объекты, записки и подписи разрешено заклеивать.
- Отмена хода, подсказка, объяснение ошибки, повторное прохождение.
- Последний кадр с подсказкой только после первой проверки.
- PNG последнего подготовленного кадра 720 × 960.
- Пять событий приложения через window.postMessage. COMPLETED_EVENT один раз за открытие страницы, включая повторную игру.
- Звук выключен при старте; синтезируется собственный короткий сигнал после включения.
- Запасной пробный кадр при недоступном или повреждённом JSON.
## Соответствие требованиям трека B

| Требование | Как выполнено |
|---|---|
| Только чистый HTML, CSS и JavaScript | Ни библиотек, ни фреймворков, ни сборки |
| Изоляция | Ни одного внешнего запроса: шрифт системный, графика — собственные SVG, звук синтезируется |
| Вес игры ≤ 5 МБ | Около 200 КБ (проверяется в CI) |
| Первый экран ≤ 3 с | Около 1,9 с на сети 1,6 Мбит/с (проверяется в CI) |
| Канал «страница → приложение» | `CLOSE_EVENT`, `FINISH_EVENT`, `COMPLETED_EVENT` (один раз за открытие, повтор не дублирует), `VIBRATION_EVENT` на успех, `SHARING_EVENT` с текстом и PNG |
| Звук не запускается сам | Выключен до включения в настройках ⚙, есть переключатель и микшер |
| Без бэкенда и персональных данных | Все данные вымышленные, ничего не уходит с устройства |
| Ограничения контента | Без чужих персонажей, лотерей, таймеров и тёмных паттернов; 0+/6+ |
| Телефоны 360–430 точек | Читаемый кадр с прокруткой к действиям, есть горизонтальная раскладка |

## Запуск

**На компьютере** (нужен Node.js), из корня проекта:

```bash
npm start
```

Откройте http://localhost:8000. Сервер раздаёт папку `game` без кеша. Другой порт: `npm start -- 8001`. В Windows: `npm.cmd start`.

**С телефона** (нужен Python 3, телефон и компьютер в одной Wi-Fi-сети):

```bash
python3 -m http.server 8000 --directory game --bind 0.0.0.0
```

На телефоне откройте `http://IP-КОМПЬЮТЕРА:8000`. В Windows команда может называться `py`. Не открывайте `index.html` двойным кликом: модулям и JSON нужен HTTP.

**В песочнице.** Соберите [Android-](https://github.com/vveidi/sber-hse-hackathon-2026-android) или [iOS-песочницу](https://github.com/vveidi/sber-hse-hackathon-2026-ios) из исходников, без изменений, и вставьте адрес игры на стартовом экране. Порядок проверки и чек-лист — в [docs/09_ANDROID_PLAYTEST.md](docs/09_ANDROID_PLAYTEST.md). На защите игра показывается именно в неизменённой песочнице.

Для продакшена нужна только папка `game`: все пути относительные, её можно положить на любой статический сервер.

Для участника 3 подготовлен [рабочий комплект](docs/08_PARTICIPANT_3_WORKPACK.md): карта содержания и структуры, [протокол Android и проверки с игроками](docs/09_ANDROID_PLAYTEST.md), [предложения по улучшениям](docs/10_IMPROVEMENTS.md), [текст слайдов и речь](docs/11_PITCH_SCRIPT.md), [фактический отчёт проверок](docs/12_VERIFICATION.md).

## Контент без релиза

Всё, что видит ребёнок, лежит в [`game/data/content.json`](game/data/content.json). Его можно менять без правки кода:

| Раздел | Что настраивает |
|---|---|
| `stickers` | Наклейки: названия, картинки, цвет подложки |
| `levels` | Кадры: фон, задача, личные записки (`secrets`), обычные объекты и подписи (`keepZones`). Проверяется `rect` секрета с внутренним отступом 8 px; `sensitiveLines` описывает строки и не меняет область проверки. `form` задаёт вид записки (`phone`, `tag`, `badge`, `paper`, `message`), `anchor` — к чему привязана бирка. `keepZones` не ограничивает наклейки |
| `levels[].layouts` | Запасные раскладки записок для повторной игры |
| `feed` | Лента реакций: ники, комментарии к каждой наклейке, лайки по кадрам, реплики «подозрительного подписчика» для каждого вида секрета, звания |
| `scenes` | Живые сцены: какие анимации включены в каждой сцене, реакции, конфетти, общая скорость |

После правки запустите `npm run check:content`: проверка находит решение для каждого кадра и каждой раскладки. Испорченный файл не ломает игру: она показывает запасной пробный кадр и не засчитывает прохождение курса.

## Проверки и CI

```bash
npm test
```
```bash
npm run check:content
```
```bash
npm run check:budget
```

| Команда | Что проверяет |
|---|---|
| `npm test` | Логику, ввод, отрисовку, весь сценарий приложения, переносимость (относительные пути, ни внешних ссылок, ни библиотек) |
| `npm run check:content` | Валидность `content.json` и то, что у каждого кадра и каждой раскладки есть решение |
| `npm run check:budget` | Оценку времени первого экрана на медленной мобильной сети |

GitHub Actions запускает эти проверки и контроль веса игры при каждом Pull Request и push в `main`.

## Структура проекта

| Путь | Что находится |
|---|---|
| `game/index.html` | Экраны и кнопки |
| `game/styles/game.css` | Внешний вид, мобильная раскладка, живой слой сцен |
| `game/data/content.json` | Кадры, тексты, раскладки, лента, настройки сцен |
| `game/assets/scenes`, `game/assets/stickers` | Собственные SVG: фоны и наклейки |
| `game/src/app.js` | Сценарий экранов и связь модулей |
| `game/src/game.js`, `geometry.js` | Правила: размещение, перенос, отмена, проверка |
| `game/src/input.js` | Палец и мышь, перетаскивание |
| `game/src/content.js` | Загрузка и валидация данных, раскладки |
| `game/src/renderer.js` | Отрисовка кадра на Canvas: сцена, записки, наклейки |
| `game/src/ui.js` | Интерфейс: палитра, сообщения, лента, звание, подсказка-палец |
| `game/src/feed.js` | Подбор комментариев, реплик и званий |
| `game/src/export.js` | Постер PNG для «Поделиться» |
| `game/src/audio.js` | Синтезированные звуки и музыка |
| `game/src/bridge.js` | События для приложения |
| `game/src/assets.js` | Загрузка картинок |
| `tests/`, `tools/` | Автотесты и проверки без внешних библиотек |
| `docs/` | Документы команды: роли, механики, проверки, питч |

> **Не запускайте `tools/make-assets.py`.** Это исходный генератор графики и `content.json`: он перезапишет текущие рисунки, раскладки, ленту и настройки сцен.
