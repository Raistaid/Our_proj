# Пакет разработки «Засвет: наклей всё!»

Игра для 11–13 лет: подготовить вымышленную картинку для открытой галереи, закрыв личные сведения смешными наклейками и сохранив главный предмет.

В этом пакете — план реализации, отдельные инструкции на троих и пример данных. Запускаемой игры и готовых иллюстраций здесь ещё нет.

| Файл | Кому и зачем |
|---|---|
| [01_Project.md](./01_Project.md) | Всем: описание, цели, пять сцен, правила, структура репозитория, технологии, интерфейсы модулей и график |
| [02_Role_Gameplay.md](./02_Role_Gameplay.md) | Участнику 1: JavaScript, состояние, жесты, проверка, отмена, данные и мост приложения |
| [03_Role_Visuals.md](./03_Role_Visuals.md) | Участнику 2: интерфейс, Canvas, три фона, три наклейки и PNG-постер |
| [04_Role_Content_QA.md](./04_Role_Content_QA.md) | Участнику 3: сценарии, JSON, песочница, проверки, наблюдения, презентация и сдача |
| [05_content.example.json](./05_content.example.json) | Пример формата одной сцены; будущие изображения и остальной набор создаёт команда |

Начать с общего документа. В первые 30 минут согласовать формат данных и сигнатуры функций. Первый час закончить запуском своей страницы в официальной песочнице. Следующий общий результат — один полностью проходящий кадр.

Роли назначаются по навыкам: самый уверенный в JavaScript — 1; интерфейс/рисунки — 2; содержание, проверки и сдача — 3. Если участник 2 не пишет JS, участник 1 помогает с его кодом, а оформление первой версии сокращается.

Требования сверены с сайтом хакатона и README песочниц 17 октября 2026 года. Число сцен, график и функции модулей — предложенное командное решение.
