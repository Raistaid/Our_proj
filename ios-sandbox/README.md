# Засвет — iOS-песочница

Проект для Xcode на основе [iOS-песочницы хакатона Сбера](https://github.com/vveidi/sber-hse-hackathon-2026-ios). Кнопка **«Играть в „Засвет“»** открывает встроенную игру без сервера и интернета. Ввод URL, тестовая страница контракта и журнал событий сохранены.

## Запуск

1. На Mac установите Xcode 26 и runtime симулятора iPhone. Минимальная версия устройства — iOS 15, как в исходном проекте.
2. Распакуйте ZIP iOS-песочницы из [Releases](https://github.com/Raistaid/Zasvet/releases/latest). В папке `zasvet-ios` находятся `ios-sandbox` и `game`; оставьте их рядом.
3. Откройте `ios-sandbox/HackathonSandbox.xcodeproj`, выберите схему `HackathonSandbox` и симулятор iPhone, нажмите Run.
4. Нажмите **«Играть в „Засвет“»**. Кнопка журнала вверху показывает события игры и действия оболочки.

Для запуска на физическом iPhone выберите свою Team в Signing & Capabilities. В проекте нет чужой команды подписи. ZIP содержит исходники для Xcode, а не установочный IPA.

При открытии проекта из Git-репозитория шаги те же: `ios-sandbox` и `game` уже расположены рядом. Xcode копирует `../game` как папку ресурсов, сохраняя пути JS-модулей, JSON, стилей и изображений. Вручную создавать вторую копию игры не нужно.

## Контракт Сбера

| Сообщение игры | Действие песочницы |
|---|---|
| `CLOSE_EVENT` | Закрывает игру и возвращает стартовый экран |
| `COMPLETED_EVENT` | Показывает «Прогресс засчитан»; отмечает повторы в журнале |
| `FINISH_EVENT` | Показывает «Игра завершена» |
| `VIBRATION_EVENT` | Вызывает тактильный отклик `.medium` |
| `SHARING_EVENT` | Открывает системное меню с текстом и PNG-постером |

Мост устанавливается до загрузки страницы и слушает обычный `window.postMessage`. Обработчики сообщений, системный обмен изображениями и журнал взяты из исходной песочницы. Сохранены её настройки: `WKWebsiteDataStore.nonPersistent()`, звук и видео после действия пользователя, блокировка переходов на другой origin и новых окон. Каждый запуск игры создаёт новую сессию.

Встроенная игра доступна по `zasvet://game/index.html`: `WKURLSchemeHandler` отдаёт только файлы из папки `game` с подходящими MIME-типами. Это позволяет загружать ES modules и JSON без локального сервера и приватных настроек WebKit. Обычные HTTP(S)-адреса и тестовая страница продолжают работать как в исходном шаблоне.

Для dev-сервера в симуляторе можно использовать `http://127.0.0.1:8000/` после `npm start` в корне Git-репозитория. Для телефона запустите сервер с `HOST=0.0.0.0 npm start` и укажите локальный IP компьютера. HTTP и локальная сеть разрешены настройками исходной песочницы.

## Проверки

Из корня Git-репозитория, на Mac с Xcode и установленным симулятором iPhone:

```bash
python3 tools/check-ios.py
```

Команда выбирает доступный симулятор, компилирует приложение и запускает XCTest без подписи. Тесты проверяют контракт сообщений, загрузку настоящей игры и её ресурсов в WKWebView, экспорт PNG 720 × 960 и доставку всех пяти событий из игрового JS-модуля. Проверка не выпускает IPA.

Из распакованного ZIP те же тесты запускаются через **Product → Test** в Xcode. Скрипты репозитория в исходный ZIP не включены.

Архивы для README обновляются из корня Git-репозитория:

```bash
python3 tools/package-downloads.py
python3 tools/package-downloads.py --check
```
